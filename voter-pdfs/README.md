# वोटर लिस्ट PDF फाइलें

इस फ़ोल्डर में प्रोजेक्ट की वोटर लिस्ट PDF फाइलें रखी जा सकती हैं।

## जरूरी गोपनीयता सूचना

इस GitHub repository की मौजूदा सेटिंग **Public** है। यहाँ अपलोड की गई PDF और उनमें मौजूद मतदाताओं के नाम, पते, EPIC नंबर आदि कोई भी देख सकता है।

**PDF अपलोड करने से पहले repository को Private करें।** निजी जानकारी वाली PDF को Public repository में अपलोड न करें।

## PDF अपलोड कैसे करें

1. इस फ़ोल्डर को खोलें।
2. **Add file → Upload files** चुनें।
3. अपनी PDF फाइलें चुनें (उदाहरण: `ward-01.pdf`, `ward-02.pdf`)।
4. नीचे **Commit changes** दबाएँ।

यह फ़ोल्डर अभी केवल PDF रखने के लिए है। इसमें PDF अपलोड होने से वे अपने-आप APK में शामिल या ऐप में आयात नहीं होंगी; उसके लिए ऐप में अलग से डेटा-लोड करने की व्यवस्था करनी होगी।
