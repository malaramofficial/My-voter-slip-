# मेरी वोटर पर्ची

Android ऐप — स्थानीय PDF से हिंदी/देवनागरी OCR, टेक्स्ट खोज और चुने हुए टेक्स्ट को शेयर करने के लिए।

## अभी उपलब्ध शुरुआती सुविधाएँ
- फोन से PDF चुनना
- PDF पेजों पर bundled Devanagari OCR चलाना
- निकाला गया टेक्स्ट फोन पर स्थानीय रूप से रखना
- OCR टेक्स्ट में खोज करना
- चुनी गई OCR लाइन को अलग से शेयर करना
- इंटरनेट permission नहीं है

## ध्यान दें
यह शुरुआती बिल्ड OCR परिणामों को लाइनों के रूप में दिखाता है; यह अभी निर्वाचन सूची के हर फॉर्मेट से नाम, पिता/पति का नाम, मकान नंबर और EPIC नंबर को भरोसेमंद संरचित रिकॉर्ड में अलग करने की गारंटी नहीं देता। OCR गलतियों की समीक्षा जरूरी है। परिवार का संबंध केवल समान मकान नंबर से तय नहीं किया जाना चाहिए।
